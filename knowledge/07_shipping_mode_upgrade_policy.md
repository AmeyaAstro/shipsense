# Shipping Mode Upgrade Policy

> **FICTIONAL DOCUMENT.** Synthetic policy written for the ShipSense portfolio project. "ShipSense Logistics" is not a real company and none of this is real operational guidance.

## When upgrades are allowed
We may upgrade an order's shipping mode at our own cost to protect the delivery promise. Upgrades
are considered for high-risk orders and for orders already 1 day late at the first carrier scan.

## Approval limits
| Upgrade | Who can approve | Maximum extra cost per order |
|---|---|---|
| Standard Class to Second Class | Fulfilment Lead | $40 |
| Second Class to First Class | Fulfilment Lead | $60 |
| Any mode to Same Day | Regional Operations Lead | $120 |

Upgrades above these limits need the Logistics Duty Manager's approval.

## Eligibility rules
- Order value must be above $500, or the customer must be in the Corporate segment.
- Upgrading to First Class is discouraged because First Class itself is frequently late;
  prefer Same Day when speed truly matters.
- Each customer can receive at most 3 courtesy upgrades per calendar quarter.

## Record keeping
Every upgrade must be logged with the reason code UPG-RISK (model flag) or UPG-LATE (already late).
