# Knowledge base (fictional)

These 11 markdown files are **synthetic** shipping policies for a made-up company, "ShipSense
Logistics", written for the ShipSense portfolio project. They exist so the RAG copilot has
documents to retrieve and cite. They are not real operational, legal or financial guidance.

Facts are deliberately specific (hours, percentages, dollar limits) so the evaluation in
`eval/questions.jsonl` can check answers objectively. Shipping modes, scheduled days, markets
and customer segments match the DataCo dataset used by the model. This README is not indexed.
